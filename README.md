## 读研意味着什么？

先来看一下读研意味着什么吧，如果你选择读研，意味着要在24-30岁这6年间完成一辈子最重要的几件大事：
* 进行一项学术研究并有一定的成果
* 找到一个靠谱的行业、在日益激烈的职场竞争中脱颖而出
* 抽出时间谈个恋爱成个家

读研是孤独的，这是字面意思，**读研意味着在周围人开始晒结婚证、晒娃、晒工资条的时候，你自己仍然在求学，25岁对于研究生而言可能还在准备毕业论文，正在应对答辩**。

读研的时间投入，可能短时间内见不到回报。根据《中国劳动力动态调查: 2019 年报告》，我国劳动力平均受教育年限为13.6年，读研，意味着达到平均水平的差不多两倍。然而，两倍的受教育时间，却不能让每个人都感受到双倍的快乐。面对这样的落差感，你需要很小心地运用自己的理性，才不会轻易被到处贩卖的焦虑所裹挟，购买大量昂贵的安慰剂、作出短视的决定。

当然，读研也并非一无是处，最直接的一点就是，读研可以为你**带来一次切换竞争赛道的机会**。其次研意味着**自身知识体系的梳理和升级**，确实可以增加自己的见识，另外研究生学历相较于本科生，的确**享有更好的福利政策**。
